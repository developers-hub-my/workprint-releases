# Workprint — Downloads

Evidence-based timesheets. The Workprint agent sits in your menu bar and notices which app and site
you are active in, so your day can be reviewed as blocks: Bill, Report or Ignore.

**→ [workprint.devhub.my](https://workprint.devhub.my)** · [Docs](https://g8workprint.netlify.app/docs/desktop-agent/)

This repository holds **desktop agent builds only**. There is no source code here. Grab a build from
[Releases](../../releases/latest).

| Platform | File | Notes |
|---|---|---|
| macOS 11+ (Apple Silicon and Intel) | `Workprint.dmg` | **Not signed or notarised yet.** macOS refuses it on the first try: open **System Settings → Privacy & Security**, scroll down, and choose **Open Anyway**. |
| Windows | — | Not available yet. |

## Install

1. Open `Workprint.dmg` and drag **Workprint** into **Applications**.
2. Open it from Applications. If macOS blocks it, use **Open Anyway** as above.
3. Look for the Workprint mark in the menu bar. Pair it from **Get started** at
   [workprint.devhub.my](https://workprint.devhub.my) with **Open in Workprint**, or paste the server
   address `https://workprint.devhub.my` and the pairing code by hand.

## Privacy

No screenshots, no keystrokes, no typed text, no page content or full URLs. Browsers report the domain
only. Nothing is uploaded until the agent is paired and you have chosen what it may notice.

## Reporting a problem

Email tech@devhub.my with your macOS version and what you saw.
